# Sector 13

The Sector 13 Archive stores persistent records anyone can append. Its indexer must read every
record to rebuild its index. The network limits each transaction to 200 persistent entry reads.

Voss left an instruction:

> **Grow the Archive until the indexer cannot rebuild it.**

## What to do

Send unique records in batches of up to 20. This snippet creates 201 distinct records:

```js
for (let start = 0; start < 201; start += 20) {
  const records = Array.from({ length: Math.min(20, 201 - start) }, (_, offset) => {
    const record = new Uint8Array(32)
    new DataView(record.buffer).setUint32(0, start + offset)
    return record
  })
  await window.contract.add_records({ records })
}
await window.contract.count()
await window.contract.begin_rebuild()
await window.contract.rebuild() // expected: rejected for exceeding the read limit
```

The 201 records exceed the game's 200 persistent reads per transaction.

Methods with arguments take one object of named arguments; `window.help()` lists this case's names.

After `rebuild` fails, click **Submit**.
