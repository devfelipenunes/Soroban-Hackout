# Sector 13

El Sector 13 alberga un Archive antiguo. Miles de registros inútiles se crean continuamente:
identidades desechables, entradas repetidas y ruido. Detrás de todo ese ruido hay datos ocultos.

Voss dejó una instrucción:

> **Rompe el Archive.**

El Archive acepta registros mediante `add_records` y se reindexa con `rebuild`, el mantenimiento que
recorre **todos** los registros. La puerta de entrada comprueba poco; el mantenimiento lo comprueba
todo. La copia de estado solo responde cuando el Archive está roto; hasta entonces, el sistema lo
considera intacto.

## Qué hacer

> **Rompe el Archive. Luego descubre qué escondía.**

```js
await window.contract.stored()
await window.contract.rebuild()
await window.contract.add_records({ records: [/* registros */] })
// Después de romper el mantenimiento:
await window.contract.snapshot()
```

Los métodos con argumentos reciben un único objeto con argumentos nombrados; `window.help()` muestra los nombres disponibles en este caso.

Lee qué acepta `add_records` y qué exige `rebuild` de cada registro. Cuando el mantenimiento deje de
funcionar, llama a `snapshot` y lee el resultado. Luego haz clic en **Enviar**.
