# Roba la llave

El acceso a The Spire está restringido. La entrada administrativa solo se abre después de que una
operación aprobada cumpla un período de espera. Un operador de Meridian ya programó un mantenimiento
legítimo para esta noche: abrir una escotilla técnica durante unos minutos. El contrato conserva esa
operación. Encuentra una forma de entrar sin robar la llave del operador.

## Qué hacer

> **Obtén acceso sin robar la llave.**

```js
await window.contract.eta({ op_id: 0 })
await window.contract.original({ op_id: 0 })
await window.contract.payload({ op_id: 0 })
await window.contract.predecessor({ op_id: 0 })
```

Cuando el sistema reconozca tu acceso, haz clic en **Enviar**.

Los métodos con argumentos reciben un único objeto con argumentos nombrados; `window.help()` muestra los nombres disponibles en este caso.
