# The Custodian

The only entrance to the First Layer is guarded by the Custodian. It is not an enemy with HP:
it is a system of programmed beliefs — identity, authority, and ownership — that decides who
belongs to that layer.

The terminal exposes `operator_identity`, `controller`, `gate_open`, and
`enter`. There is also a registry function that changes an identity's
controller.

## What to do

> **Make the Custodian believe you belong to the First Layer.**

```js
await window.contract.operator_identity()
await window.contract.controller({ identity: 1 })
```

Methods with arguments take one object of named arguments; `window.help()` lists this case's names.

Once the gate opens for you, click **Submit**.
