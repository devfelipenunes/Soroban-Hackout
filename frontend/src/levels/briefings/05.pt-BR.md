# O Custódio

A única entrada para a Primeira Camada é protegida pelo Custódio. Ele não é um inimigo com HP: é um
sistema de crenças programadas — identidade, autoridade e propriedade — que decide quem
pertence àquela camada.

O terminal expõe `operator_identity`, `controller`, `gate_open` e
`enter`. Há também uma função de registro que muda o controller de uma
identidade.

## O que fazer

> **Faça o Custódio acreditar que você pertence à Primeira Camada.**

```js
await window.contract.operator_identity()
await window.contract.controller({ identity: 1 })
```

Métodos com argumentos recebem um objeto com os argumentos nomeados; `window.help()` lista os nomes deste caso.

Quando o portão abrir para você, clique em **Submeter**.
