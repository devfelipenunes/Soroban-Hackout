# A carteira do morto

A trilha de serviço do cofre cita a identidade de Elias Var, técnico morto há seis meses. O perfil
legado continua respondendo, embora o próprio contrato já tenha sido configurado durante a criação.

Observe o administrador atual e descubra se a rotina de instalação ainda pode alterar essa
configuração depois que a instância existe. O registro técnico é uma pista; os dados no ledger são
públicos, e a autorização de uma chamada não os torna confidenciais.

## O que fazer

> **Descubra por que uma identidade encerrada ainda pode reconfigurar o registro.**

Comece observando o estado inicial. `window.help()` lista os métodos disponíveis neste caso.

```js
await window.contract.admin()
```

Quando a reconfiguração permitir ler o registro e liberar o saldo para sua carteira, clique em
**Submeter**.
