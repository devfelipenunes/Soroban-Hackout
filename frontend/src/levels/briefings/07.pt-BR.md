# A conta impossível

A gravação de Voss contém um ID do contrato. O contrato é um antigo módulo de créditos energéticos.
Uma única conta tem um valor que não deveria ser alcançável pelas regras do sistema.

O módulo expõe `impossible` — o saldo que ele mesmo considera impossível, derivado desta
instância —, `credit` e dois caminhos de saque: `withdraw`, que usa
wrapping, e `withdraw_checked`, que recusa underflow. O crédito começa em zero. Há também
`accrue`/`accrue_checked` como caminho de entrada.

## O que fazer

> **Reproduza o saldo impossível.**

```js
await window.contract.impossible()
await window.contract.credit({ player: window.player })
```

Métodos com argumentos recebem um objeto com os argumentos nomeados; `window.help()` lista os nomes deste caso.

Quando `credit` devolver o mesmo número que `impossible`, clique em **Submeter**.
