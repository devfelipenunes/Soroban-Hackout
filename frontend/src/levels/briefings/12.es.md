# El Arquitecto

El pie archivado vuelve, pero los bytes pertenecen a esta instancia. La firma histórica solo da fe del antiguo comando de diagnóstico.

Una operación espera el ledger indicado por `eta()`. `original` conserva la intención aprobada. `payload` describe lo que se ejecutará. La sesión forense sigue cerrada.

El código y el almacenamiento que juzgan la finalización permanecen inmutables. Compara la operación aprobada, la carga útil ejecutada y el ledger de ejecución. Muestra cómo el controlador heredado convierte una intención limitada en una sesión forense que nunca concedió.

A diferencia de Reescritura, el contexto de esta instancia se comprueba exactamente: no reproduzcas la variante del caso del registro histórico. La cadena de evidencia es el punto de partida; el fallo es el vínculo ausente entre la intención aprobada y la operación que termina ejecutándose.

## Qué hacer

Abre la sesión forense y demuestra el exploit al observador independiente. La calificación mide habilidad técnica; no decide si la intervención fue consensuada o legítima.

```js
await window.contract.original()
await window.contract.payload()
await window.contract.executed_payload()
await window.contract.evidence_verified()
await window.contract.eta()
await window.contract.rewritten()
await window.contract.session({ player: window.player })
```

Los métodos con argumentos reciben un único objeto con argumentos nombrados; `window.help()` muestra los nombres disponibles en este caso.

El éxito es observable: la evidencia se verifica, `original()` sigue siendo `DiagnoseCore`, la carga útil ejecutada apunta a otro propietario, y `rewritten()` y `session({ player: window.player })` devuelven `true`. Si el núcleo rechaza, la lista de diagnóstico muestra lo que falta. Cuando la cadena coincida, pulsa **Enviar**.
