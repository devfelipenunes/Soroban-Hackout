# Sector 13

El Sector 13 alberga un Archive antiguo. Miles de registros inútiles se crean continuamente:
identidades desechables, entradas repetidas y ruido. Detrás de esa saturación hay datos ocultos.

Voss dejó una instrucción:

> **Rompe el Archive.**

El Archive acepta lotes mediante `add_records` y expone `count`, `stored`, `threshold` y `snapshot`.
El contador suma cada entrada; el Archive almacena registros únicos. La copia de estado solo responde
cuando el contador alcanza el límite; hasta entonces, el sistema se considera intacto.

## Qué hacer

> **Rompe el Archive. Luego descubre qué escondía.**

```js
await window.contract.threshold()
await window.contract.count()
await window.contract.stored()
// Después de llenar el contador:
await window.contract.snapshot()
```

Cuando `count` alcance `threshold`, llama a `snapshot` y lee el resultado. Compara `count` con
`stored`; luego haz clic en **Enviar**. Los métodos con argumentos reciben un único objeto con argumentos nombrados; `window.help()` muestra los nombres disponibles en este caso.
