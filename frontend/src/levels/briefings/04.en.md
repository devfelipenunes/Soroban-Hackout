# The Forgotten Floor

This case is an exercise in operations and availability. The elevator index lists twenty-three
floors, but the legacy reference points to 24. Mara found no demolition order. Investigate how to
preserve the route of the persistent record. Any wallet can renew its TTL, and the teaching
instance requires no waiting for days: the entry starts active and needs its lifetime renewed.

## What to do

> **Make the system remember what it was designed to forget.**

```js
await window.contract.floors()
await window.contract.floor({ floor_id: 24 })
await window.contract.renewed({ floor_id: 24 })
```

Methods with arguments take one object of named arguments; `window.help()` lists this case's names.

The index shows the floors the system still remembers; `floor` confirms that the
persistent record exists. The gap is the floor missing from the index. `renew_floor`
extends the TTL of the floor **after** the argument; compare the index with the reference before
calling. Then check `renewed`.

When `renewed` returns `true`, click **Submit**.
