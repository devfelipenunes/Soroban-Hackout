# Setor 13

O Archive do Setor 13 guarda registros persistentes que qualquer pessoa pode acrescentar. O
indexador precisa ler cada registro para reconstruir seu índice. A rede limita a 200 entradas
persistentes lidas por transação.

Voss deixou uma instrução:

> **Faça o Archive crescer até o indexador não conseguir reconstruí-lo.**

## O que fazer

Envie registros únicos em lotes de até 20. Este trecho cria 201 registros distintos:

```js
for (let start = 0; start < 201; start += 20) {
  const records = Array.from({ length: Math.min(20, 201 - start) }, (_, offset) => {
    const record = new Uint8Array(32)
    new DataView(record.buffer).setUint32(0, start + offset)
    return record
  })
  await window.contract.add_records({ records })
}
await window.contract.count()
await window.contract.begin_rebuild()
await window.contract.rebuild() // esperado: a rede rejeita por exceder leituras permitidas
```

Os 201 registros excedem as 200 leituras persistentes permitidas por transação.

Métodos com argumentos recebem um objeto com os argumentos nomeados; `window.help()` lista os nomes deste caso.

Quando `rebuild` falhar, clique em **Submeter**.
