# Prueba técnica confirmada

Se respetó el plazo. La carga útil ejecutada fue una sesión forense para otro propietario; la llamada interna falló, el error fue ignorado y el estado `Executing` quedó activo. El Breaker abrió la sesión para sí mismo directamente, y el validador independiente comprobó la evidencia, la carga útil ejecutada y la sesión.

La firma autentica la intención de diagnóstico. El compromiso vincula la reconstrucción a la red, la instancia y la cartera; las partes públicas no son un secreto. La validación independiente exige los estados objetivos del exploit.
