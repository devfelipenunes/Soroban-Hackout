# Prologue — The Impossible Theft

Meridian woke up to its most protected vault empty.

Two million four hundred thousand, gone overnight. No private key reported stolen. No
administrative signature on record. No camera showing a break-in. The Vault contract still
answers normally — and the balance is zero.

The case belongs to **Mara Vale**, an investigator with the Meridian Authority. She believes
what the system shows. Looking at the last transaction, Mara concludes:

> "The system accepted the transaction. That means someone was authorized."

You watch the records for a few seconds. Then you answer:

> "No. It means the contract believed someone was authorized."

Mara does not like the answer. But she cannot refute it either.

You are an independent contract auditor. This is your first case, and it begins with the
question nobody in the room wants to ask:

> **If no key was stolen, how did they get in?**

## What to do

The Authority's terminal opens a training contract so you can prove you can operate the city's
programmable layer. It starts at zero.

**Make the counter reach one.**

If you have never talked to a contract from the console, start like this — with an instance
already created:

```js
// who you are, and which contract is yours
window.player
window.instance

// read before you write
await window.contract.count()

// register your presence
await window.contract.increment()

// and check
await window.contract.count()
```

Methods with arguments take one object of named arguments; `window.help()` lists this case's names.

There is no text box on this page: the console is the interface.

> This level's code stays hidden until you solve it. There is no bug here — what exists is the
> loop you will use in every other case.

Once the counter reaches one, click **Submit**.
