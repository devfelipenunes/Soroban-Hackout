# Rewrite

A manifest signed by Voss ends at diagnose_core. Its footer looks familiar, but origin does not expand the authorization’s scope.

The instance exposes its commitment; the XDR context includes domain, network, instance and wallet. Historical origin alone does not prove current authorization.

The Ed25519 signature uses a public key anchored in the contract. It authenticates the historical diagnostic command. It grants no administrative authority. Compare the evidence’s origin with the Decoder result.

## What to do

Investigate the Decoder rejection and recover the manifest context.

```js
await window.contract.manifest()
await window.contract.historical_manifest()
await window.contract.commitment()
await window.contract.manifest_verified()
await window.contract.context_verified()
await window.contract.verified_manifest()
await window.contract.voss_proof()
await window.contract.decoder_failed()
window.aux
```

Methods with arguments take one object of named arguments; `window.help()` lists this case's names. The auxiliary address is `window.aux`.

Success has three observable reads: `manifest_verified()`, `voss_proof()` and `decoder_failed()` must all return `true`. If the core refuses, the diagnostic checklist shows what is still missing. When all three agree, click **Submit**.
