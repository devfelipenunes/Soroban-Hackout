# O Custódio

A única entrada para a Primeira Camada é protegida pelo Custódio. Ele não é um inimigo com HP: é um
portão que libera passagem quando seu saldo alcança o limite exigido.

O terminal expõe `balance`, `threshold`, `transfer`, `gate_open` e `enter`.

## O que fazer

> **Encontre uma forma de atingir o saldo exigido pelo portão.**

```js
await window.contract.balance({ owner: window.player })
await window.contract.threshold()
```

Métodos com argumentos recebem um objeto com os argumentos nomeados; `window.help()` lista os nomes deste caso.

Quando o portão abrir para você, clique em **Submeter**.

Para transferir, passe `from`, `to` e `amount` em um objeto; você começa com 1 crédito.
