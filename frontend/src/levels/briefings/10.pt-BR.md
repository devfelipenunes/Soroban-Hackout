# Roube a chave

A Torre não aceita visitantes. A entrada administrativa só abre depois que a manutenção aprovada
passa pelo timelock. O operador de Meridian agendou duas operações para a mesma janela: rotacionar
a chave de serviço e, em seguida, abrir o hatch técnico por alguns minutos. O contrato mantém o
vínculo entre as duas.

Cada operação tem ID, `eta`, `original` e `payload`. O contrato expõe `rewrite_payload` e
`execute`. O operador aprovou `rotate_service_key` e `open_maintenance_hatch` — não o que você
quer.

## O que fazer

> **Roube o acesso sem roubar a chave.**

```js
await window.contract.eta({ op_id: 0 })
await window.contract.original({ op_id: 0 })
await window.contract.payload({ op_id: 0 })
await window.contract.predecessor({ op_id: 0 })
```

Métodos com argumentos recebem um objeto com os argumentos nomeados; `window.help()` lista os nomes deste caso.

Quando `access` devolver `true` para a sua carteira, clique em **Submeter**.
