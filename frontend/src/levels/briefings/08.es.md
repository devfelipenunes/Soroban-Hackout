# Sector 13

El Archive del Sector 13 guarda registros persistentes que cualquiera puede añadir. Su indexador
debe leer cada registro para reconstruir el índice. La red limita cada transacción a 200 lecturas
de entradas persistentes.

Voss dejó una instrucción:

> **Haz crecer el Archive hasta que el indexador no pueda reconstruirlo.**

## Qué hacer

Envía registros únicos en lotes de hasta 20. Este fragmento crea 201 registros distintos:

```js
for (let start = 0; start < 201; start += 20) {
  const records = Array.from({ length: Math.min(20, 201 - start) }, (_, offset) => {
    const record = new Uint8Array(32)
    new DataView(record.buffer).setUint32(0, start + offset)
    return record
  })
  await window.contract.add_records({ records })
}
await window.contract.count()
await window.contract.begin_rebuild()
await window.contract.rebuild() // esperado: la red rechaza la operación por superar el límite
```

Los 201 registros superan las 200 lecturas persistentes permitidas por transacción.

Los métodos con argumentos reciben un único objeto con argumentos nombrados; `window.help()` muestra los nombres disponibles en este caso.

Después del fallo de `rebuild`, haz clic en **Enviar**.
