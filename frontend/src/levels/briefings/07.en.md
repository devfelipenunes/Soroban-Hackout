# The Impossible Account

Voss's recording contains a contract ID. The contract is an old energy-credit module. A single
account holds a value that should not be reachable under the system's rules.

The module exposes `impossible` — the balance it itself calls impossible, derived from this
instance —, `credit`, and two withdrawal paths: `withdraw`, which uses
wrapping, and `withdraw_checked`, which refuses underflow. The credit starts at zero. There is
also `accrue`/`accrue_checked` as an entry path.

## What to do

> **Reproduce the impossible balance.**

```js
await window.contract.impossible()
await window.contract.credit({ player: window.player })
```

Methods with arguments take one object of named arguments; `window.help()` lists this case's names.

Once `credit` returns the same number as `impossible`, click **Submit**.
