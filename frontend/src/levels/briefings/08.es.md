# Sector 13

El Sector 13 alberga un Archive antiguo. Miles de registros inútiles se crean continuamente:
identidades desechables, entradas repetidas y ruido. Detrás de todo ese ruido hay datos ocultos.

Voss dejó una instrucción:

> **Rompe el Archive.**

El Archive acepta registros mediante `add_records`: cada registro tiene un **peso**, la carga que
suma al archivo. Se reindexa con `rebuild`, el mantenimiento que recorre **todos** los registros y
totaliza los pesos. La puerta de entrada comprueba cada peso por separado; el mantenimiento trabaja
con el total. La copia de estado solo responde cuando el mantenimiento dejó de funcionar; hasta
entonces, el sistema considera el Archive intacto.

## Qué hacer

> **Rompe el Archive. Luego descubre qué escondía.**

```js
await window.contract.stored()
await window.contract.rebuild()
await window.contract.add_records({ weights: [/* pesos, números */] })
// Después de romper el mantenimiento:
await window.contract.snapshot()
```

Los métodos con argumentos reciben un único objeto con argumentos nombrados; `window.help()` muestra los nombres disponibles en este caso.

Lee qué comprueba `add_records` en cada peso y qué hace `rebuild` con todos ellos. Cuando el mantenimiento deje de
funcionar, llama a `snapshot` y lee el resultado. Luego haz clic en **Enviar**.
