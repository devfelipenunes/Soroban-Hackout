# Steal the Key

The Spire does not accept visitors. The administrative entrance only opens after the approved
maintenance passes through its timelock. The Meridian operator scheduled two operations for the
same window: rotating the service key, then opening the technical hatch for a few minutes. The
contract keeps the link between them.

Each operation has an ID, an `eta`, an `original` and a `payload`. The contract exposes
`rewrite_payload` and `execute`. The operator approved `rotate_service_key` and
`open_maintenance_hatch` — not what you want.

## What to do

> **Steal access without stealing the key.**

```js
await window.contract.eta({ op_id: 0 })
await window.contract.original({ op_id: 0 })
await window.contract.payload({ op_id: 0 })
await window.contract.predecessor({ op_id: 0 })
```

Methods with arguments take one object of named arguments; `window.help()` lists this case's names.

Once `access` returns `true` for your wallet, click **Submit**.
